# Royal Neon Casino 사용 설명서 & 배포 가이드

Royal Neon Casino는 설치나 서버 실행 없이 웹 브라우저에서 바로 구동 가능한 100% 정적(Static) 싱글 페이지 도박 게임입니다. 본 가이드는 게임 방법과 이를 외부 인터넷에 업로드하여 친구들과 공유할 수 있는 무료 웹 배포 방법을 설명합니다.

## 🎮 게임 설명 및 규칙

  - 대기 시간이나 횟수 제한 없이 자유롭게 충전하여 게임을 계속 플레이할 수 있습니다.

### 2. 홀짝 동전 Flip
- **게임 방식**: 생성되는 무작위 자연수(1~99)가 홀수(Odd)인지 짝수(Even)인지 예측하여 배팅합니다.
- **배당률**: **2.0배**
- **확률**: **정직한 50.0%** (100% 무작위 추첨)

### 3. 주사위 Roll

- **단일 숫자 맞추기 모드**: 1부터 6까지의 주사위 눈 중 정확히 나올 숫자를 하나 골라 배팅합니다.

### 5. 3-Card 행운의 카드 뽑기 (Card Draw)
- **게임 방식**: 3장의 뒷면 카드(Card 1, 2, 3) 중 마음에 드는 1장을 선택하여 뒤집습니다.
- **배당 및 확률**:

## 🌐 인터넷에 무료로 배포하는 방법

Royal Neon Casino는 백엔드 서버나 DB가 필요 없는 100% 정적 파일이므로, 무료 정적 호스팅 서비스를 통해 1분 만에 인터넷 웹사이트로 배포할 수 있습니다.

### 방법 A: Netlify를 이용한 초간단 배포 (가장 추천)
회원가입 후 마우스 드래그 한 번으로 배포하는 방법입니다.

1. [Netlify 공식 사이트](https://www.netlify.com/)에 접속하여 회원가입(Sign up)합니다.
2. 로그인 후 대시보드에서 **Sites** 메뉴로 이동합니다.
3. 화면 하단의 **"Want to deploy a new site without connecting to Git? Drag and drop your site folder here"** 영역을 찾습니다.
4. `index.html` 파일이 들어있는 **폴더 전체(취미 폴더 등)**를 해당 영역에 드래그 앤 드롭합니다.
5. 몇 초간의 업로드 후 즉시 고유한 주소(예: `https://glowing-casino-12345.netlify.app`)가 생성되어 전 세계 어디서든 링크로 접속할 수 있게 됩니다.

### 방법 B: GitHub Pages를 이용한 배포
소스 코드를 관리하면서 무료로 도메인을 유지하는 방법입니다.

1. [GitHub](https://github.com/) 계정을 생성하고 로그인합니다.
2. 새 저장소(New Repository)를 생성합니다. (이름 예: `neon-casino`, Public으로 설정)
3. 생성된 저장소에 `index.html` 파일을 업로드하고 커밋(Commit)합니다.
4. 저장소의 **Settings** -> **Pages** 메뉴로 이동합니다.
5. Build and deployment의 Branch를 `None`에서 `main` (또는 `master`)으로 변경하고 옆의 `/ (root)` 설정을 확인한 뒤 **Save**를 누릅니다.
6. 약 1~2분 뒤 상단에 `https://<유저네임>.github.io/neon-casino/` 형식의 배포 완료 웹사이트 링크가 생성됩니다.

### 방법 C: Vercel을 이용한 배포
깔끔한 UI와 빠른 속도를 자랑하는 클라우드 호스팅 서비스입니다.

1. [Vercel 공식 사이트](https://vercel.com/)에 접속하여 가입 후 로그인합니다.
2. 대시보드에서 **Add New...** -> **Project**를 클릭합니다.
3. GitHub 저장소와 연동하여 `index.html`이 담긴 레포지토리를 선택하고 **Deploy** 버튼만 누르면 수초 이내에 무료 웹 주소로 자동 배포됩니다.
